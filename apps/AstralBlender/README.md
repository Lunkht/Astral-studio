# AstralBlender

Clone minimaliste de Blender (3D), en HTML/CSS/JS pur (Canvas 2D), sans dependance ni build.

Application de la suite **Astral Studio** (depot `Astral-studio`, dossier `apps/AstralBlender`).

Statut : **a venir** (dossier cree, implementation non commencee).

## Perimetre envisage

- Modelisation 3D : primitives, sommets/aretes/faces, transformations, extrusion.
- Vue 3D orbitale (projection et rasterisation logicielles sur Canvas 2D, sans WebGL/WebGPU).
- Materiaux/couleurs simples, eclairage de base, rendu d'image et export.
