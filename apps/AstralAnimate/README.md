# AstralAnimate

Clone minimaliste d'Adobe Animate (animation 2D), en HTML/CSS/JS pur (Canvas 2D), sans dependance ni build.

Application de la suite **Astral Studio** (depot `Astral-studio`, dossier `apps/AstralAnimate`).

Statut : **a venir** (dossier cree, implementation non commencee).

## Perimetre envisage

- Animation image par image, timeline et images cles.
- Symboles / instances, interpolation de mouvement (tween) et de forme.
- Dessin vectoriel simple, previsualisation et export.
